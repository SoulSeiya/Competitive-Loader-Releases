Competitive Loader 1.5.9
Compatible con Tenkaichi3Decomp 0.1.35.4 y 0.1.35.2.

Esta version publica contiene las partidas normales de Dragon Net Battle.
El desarrollo experimental de salas, torneos, bots y espectadores se conserva fuera de este repositorio.

Funciones:
- Host / Quick match / Join y room codes del menu original.
- Matchmaking BTC propio: https://btc-matchmaking.paulogomez41.workers.dev
- FT1 a FT5, marcador persistente, nombres de jugadores y GG al terminar el set.
- Tiempos online de 180, 240, 360 y 480 segundos, ademas de sin limite.
- Correcciones de intro, audio y modelos de efectos, incluido el fallo de Androide 16.
- Chat original con Tab y bloqueo de movimiento/redimensionado de ventana durante el online.
- Registros locales y online por sesion, con crash y desync cuando el juego los reporta.
- Buscar actualizaciones sin reiniciar: cache de cinco minutos y consulta de Releases publicas si GitHub limita su API.
- Validacion del decomp y de los parches antes de iniciar o instalar una actualizacion.

Extrae el ZIP en una carpeta propia y abre Competitive Loader.exe.
Necesitas tu propia ISO competitiva y, opcionalmente, tu memory PCSX2.
Ambos jugadores deben usar las mismas versiones y datos compatibles.
Manten el Loader abierto durante la partida para guardar registros y proteger la memory online.
Al actualizar, conserva CompetitiveRuntime y competitive_loader.json.
El ZIP no contiene ISO, memory ni configuracion personal.

Los ensayos locales no sustituyen las pruebas online prolongadas entre equipos.
